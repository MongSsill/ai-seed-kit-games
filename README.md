# 게임 작업실 — AI와 함께 만든 작은 게임 셋

넷마블네오 AI 인턴십 지원 포트폴리오. 코딩을 처음 하는 사람이 AI(Claude Code)에게 코드를 맡기고, 무엇을 만들지와 됐는지는 직접 정하며 한 판 30초~3분짜리 게임 셋을 차례로 끝까지 만들었다. 모두 PC 키보드용이고, 링크로 바로 열리며, 폴더를 받아 index.html 을 더블클릭해도 돌아간다.

## 게임 셋

| 게임 | 바로 해 보기 | 한 줄 소개 |
|---|---|---|
| 1 완전 카피 — 길 건너기 | https://mongssill.github.io/ai-seed-kit-games/g1-copy/ | 한 칸씩 길을 건너는 무한 진행 게임을 그대로 따라 만든 것 (g1-copy/README.md) |
| 2 큰 게임의 일부 — 태그 보스전 | https://mongssill.github.io/ai-seed-kit-games/g2-slice/ | 보스 공격의 전조에 맞춰 태그·회피로 반격하는 세 캐릭터 보스전 한 판 (g2-slice/README.md) |
| 3 창작 데모 — Chain Echo | https://mongssill.github.io/ai-seed-kit-games/g3-original/ | 세 캐릭터를 태그로 이어 길을 여는 2D 도트 플랫포머, 스테이지 1-1~1-5 와 보스 (g3-original/README.md) |

게임 3 은 한 판이 스테이지 하나(30초~3분)이고, 앞 스테이지를 깨야 다음이 열린다.

## 무엇을 왜 만들었나 (내 말로)

게임의 핵심 재미를 이용한 확장성 높은 창작 게임을 만들기 위해서 이전 두 개의 게임으로 테스트를 한 후 빌드하였다. 진행 과정에서 레벨 디자인을 통한 자연스런 조작 방법 숙달 또한 부가적 목표로 설정하였다.

## AI와 어떻게 나눠 일했나, 쓴 도구

- 나눈 방식 (CLAUDE.md 의 내 말): 코딩은 처음이다. 코드를 읽고 고치는 일은 맡기고, 무엇을 만들지와 됐는지 아닌지는 내가 정한다.
- Claude Code: 코드 작성·수정, 화면 없는 크롬으로 자동 검사(게임 1·2·3 각각 검사 묶음, 게임 3 은 207개)와 장면 사진, 결정 기록·작업 표·로그 정리. 만든 과정을 보지 않은 검토 역할(reviewer)로 따로 검토
- ChatGPT: 레퍼런스와 방향을 정해 그림 시트·효과음을 만들고 후가공 → Claude Code 가 잘라 게임 톤에 맞춰 넣음
- GitHub Pages: 링크로 공개
- 기록: logs/ 하루 한 장 실험 로그, docs/decisions.md 결정 기록, 게임마다 steps/ 에 작업 단계별 모습

## 받아서 시작한 것과 내가 바꾼 것

- 받아서 시작한 것: 이 작업실의 규칙(CLAUDE.md), 명령(/start /end /retro), 검토 역할(reviewer), 문서 양식(templates/)
- 내가 바꾼 것: LESSONS.md 의 "고친 이력" 20번 (규칙·명령을 고친 기록). AI 가 틀리거나 내가 고치게 한 일은 같은 파일 장부에 99줄로 쌓았다

## 세 게임을 거치며 달라진 것 (내 말로)

AI활용 능력, 게임의 핵심 재미에 기여하는 자칫 놓치기 쉬운 요소들(효과음, 제한 사항, 편의성 등)에 대한 이해도 상승, 에셋과 작업 규칙 누적으로 인한 이후 게임 빌드 시 속도 가속화
