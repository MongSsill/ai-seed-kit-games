# 원작 분해 (게임 1 완전 카피)

한 판이 30초 안팎인 아주 작은 게임을 고른다. 예: 똥 피하기, 플래피 버드, 벽돌 깨기, 스네이크, 2048.

- 원작: 길건너친구들, 스마트폰
- 고른 이유 (내 말로): 간단한 플레이방식이지만 반복적인 플레이를 유도하고, 장애물의 종류와 속도 및 여러 변수를 통하여 게임에 변주를 다각도로 줄 수 있는 점이 단순한 게임이지만 유저들의 사랑을 받을 수 있게 만들었다고 생각했기 때문

## 해 보고 적은 것

원작을 열 판 이상 해 보고 적는다. 본 것과 짐작한 것을 나눠 적는다.

| 무엇 | 본 것 | 짐작한 것 |
|------|-------|-----------|
| 규칙 (어떻게 시작하고 어떻게 끝나나) | 플레이어는 캐릭터를 좌/우/전방/후방  네 방향으로 조작할 수 있고 장애물을 피해서 앞으로 전진하는 것을 목표로 한다. 한 자리에 오래 머물거나 이동을 할 때 마다 화면이 앞으로 밀려오고, 뒤로 처지면 게임 오버가 된다. 게임 내의 장애물의 종류에는 자동차, 움직이는 발판, 빈 공간 등이 존재한다. 열차랑 나무랑 돌은 직접 본 것들이다. 빈 공간은 호수나 하늘을 말한다. | |
| 조작 | 화면의 좌측을 슬라이드 하면 좌측이동, 우측을 슬라이드 하면 우측 이동, 앞으로 슬라이드 하면 전진 이동, 아래로 슬라이드하면 후방 이동. 좌우후방은 슬라이드만, 전방은 탭 및 슬라이드. | |
| 수치 (속도, 간격, 점수) | 초반에는 장애물의 속도가 느렸지만 150칸 전진 이후부터는 급격히 빨라지는 것을 체감했다. 점수는 200점 이상이면 나름 높은 점수였다. | |
| 반응 (눌렀을 때, 맞았을 때, 끝났을 때 화면과 소리) | 한걸음 갈때마다 톡톡 소리가 나면서 내딛는 행위에 대한 피드백을 확실히 주었고, 차에 캐릭터가 들이박았을 때는 차에 찌그러지는 모션, 물에 빠지면 물 웅덩이가 출렁이는 모션 등 게임 오버에 대한 이펙트도 존재했다. | 인게임 플레이와 게임 오버에 대한 피드백을 강화하는 것에 중점을 두었다고 느낄 수 있었다. |
| 어려워지는 방식 | 중간에 휴식할 수 있는 쉼터가 줄어든다거나, 도로의 차선이 늘어나고 차들의 속도가 빨라져서 차를 피하기 힘들어진다거나, 움직이는 발판의 크기가 줄어들어 발판을 갈아타기 힘들어지는 등의 요소로 난이도를 상승시켜 고득점을 어렵게 만드는 방법을 사용했다. | |

## 어디까지 똑같이 할까

- 똑같이 할 것: wasd 및 방향키로 조작하기, 장애물의 종류는 열차(매우빠르고 예고 사인이 존재함), 자동차(차길에서만 다님), 움직이는 발판 및 밟으면 떨어지는 물로 한정하자. 이외에는 옵젝들(나무, 돌)등으로 이동 방향만 제한할 수 있도록 하자. 빈 공간(호수나 하늘)도 넣는다. 게임 오버 규칙: 장애물을 피하지 못하거나 뒤로 처지게 되면 게임 오버가 된다.
- 뺄 것과 이유: 캐릭터 해금 및 종류를 3가지로 제한하자. 원작은 여러가지가 있고, 코인을 통해 해금했지만 그건 너무 과다하다고 생각해.
- 원작과 다르게 할 것과 이유: 한번 밟으면 다시 밟을 수 없이 사라지는 발판을 넣는다 (원작에는 없다). 캐릭터는 해금을 통하여 고를 수 있는 형태로 도입한다. 세 번째는 기본 캐릭터다. 1) 15연속 전진 시 0.5초 이상 전방 키를 누르고 있다가 떼면 앞으로 두칸 점프(뛰어넘기 가능)하는 개구리 캐릭 (15연속 전진은 개구리를 푸는 조건이다. 좌우후방이동 행위를 제외하고 한 게임에서 연속으로 15회 전진을 성공했을 시에만 해금된다.) 2) 차에 치여서 30번 사망할 시 차에 치여서 죽는 것을 한번 방지해주는 황소 캐릭터 (누적이기 때문에 한 게임에서 해당 수치를 달성할 필요는 없다.). 게임 오버 시 해당 과제를 달성했는지 여부를 결과창에 같이 띄워주는 식으로 심사위원이 확인할 수 있게 한다. 카피게임이라고 완벽히 카피만 해놓는 것 보다는 약간의 변주를 주는 쪽이 조금 더 좋다고 생각한다.
- 한 문장: 캐릭터가 4방향의 키보드 조작을 통하여 각종 장애물을 피하며 최대한 전진하는 것을 목표로 하는 게임.
