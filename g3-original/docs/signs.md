# 표지판 문장 목록

게임 3 의 표지판 13개 (1-1 다섯, 1-2 셋, 1-3 둘, 1-4 둘, 1-5 하나). 표지판 가까이(약 2칸) 가면 그 위에 말풍선이 열린다. 2026-11-24 game.js 에서 옮겨 적음.

## 쓰는 법

- "바꿀 제목 줄"과 "바꿀 설명 줄"을 채우면 그대로 게임에 넣는다. 비워 두면 지금 문장을 그대로 둔다.
- 제목 줄은 금빛 굵은 글씨, 설명 줄은 흰 글씨로 나온다. 두 줄까지만 나온다.
- `[S]` 처럼 대괄호로 감싼 것은 키 모양 그림으로 그려진다. 쓸 수 있는 키: `[←]` `[→]` `[↑]` `[Space]` `[A]` `[S]` `[D]` `[F]` `[Shift]` `[E]`
- 길이: 제목 줄은 15자 안팎, 설명 줄은 30자 안팎이면 말풍선이 화면 안에 들어간다. 더 길면 말풍선이 넓어진다.
- "이 자리에서 만나는 것"은 맵을 보고 AI 가 적은 설명이다.
