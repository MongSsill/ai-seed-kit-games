# CHAIN ECHO — Impact / Non-melodic SFX Patch

이전 Heavy 패치 25종 재설계 + 통합 2종 갱신. 나머지 기존 에셋 유지.
- 음계/아르페지오/반복 알림음 대신 충격, 비정수배 금속 공명, 필터링 노이즈, 마력 흡수 및 짧은 잔향 사용.
- 기존 파일명, 정확한 샘플 수, stereo PCM16 / 44100Hz 유지.
- 게임에 복사할 것은 `assets/audio/` 내부 27개뿐. `previous/`와 `compare.html`은 비교 청취 전용.
- 기존 gain 및 이벤트 타이밍은 우선 유지. 패링 이벤트의 실제 로컬 연결은 미확인.
- PERFECT는 타격+파쇄, 패링은 강철 충돌, 일반 태그는 공기 이동+결합으로 구별.
- 통합 믹스와 개별 이벤트를 동시에 재생하지 말 것. world_door_full: 0/.32/.64/.96초 결합, 1.28초 개방. 체인 에코 기존 manifest 타이밍 유지.
- 합성 시안: 샘플 수·포맷·클리핑 검증, 실제 청취 및 인게임 밸런싱 미실시.
