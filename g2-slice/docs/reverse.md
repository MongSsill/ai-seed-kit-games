# 역기획 한 쪽 (게임 2 큰 게임의 일부)

많이 해 본 큰 게임에서 재미의 한 조각을 고른다. 전투의 한 연계, 강화 연출, 미니게임 하나처럼 30초에서 3분 안에 해 볼 수 있는 조각이다. 지원하는 회사의 게임에서 고르면 지원 동기와 이어진다.

- 원작과 조각: 몬길: 스타다이브 (개발 넷마블몬스터, 배급 넷마블. 2026-04-15 PC·모바일 출시, 3인 파티 태그 플레이 액션 RPG). 보스 전투의 교체 스킬 메커니즘. 보스 공격의 전조가 빛나는 순간에 회피를 입력하면 회피 반격, 교체를 입력하면 교체 스킬이 발동한다
- 얼마나 해 봤나: 약 일주일
- 고른 이유 (내 말로): 최근 플레이한 게임의 핵심 매커니즘을 재현해보는 것으로 해당 게임의 재미 요소를 직접 분석해보고 창작 게임으로 나아갈 영감을 얻기 위함.

## 이 조각이 왜 재미있는가 (내 말로)

단순한 액션이 아닌 태그 매커니즘을 통하여 캐릭터 간의 유기적인 전투를 만들 수 있으며 해당 시스템과 연출을 통하여 속도감 있는 전투를 보여주는 점이 핵심 요소라고 생각한다.

## 관찰과 추정

관찰 칸은 일주일 플레이의 기억이라 다시 확인이 필요하다. 기사나 위키로 확인된 것만 (확인) 으로 표시한다.

| 무엇 | 관찰한 것 | 추정한 것 |
|------|-----------|-----------|
| 규칙 | 보스 공격은 노란색과 붉은색 두 종류. 노란 전조가 빛나는 순간 회피를 입력하면 회피 반격, 교체를 입력하면 편성 3명 중 다음 순서 캐릭터가 등장해 교체 스킬을 쓴다. 전조에 맞춘 입력은 태그 쿨타임을 초기화한다 (확인). 회피 반격과 전조에 맞춘 교체 스킬은 그로기 게이지를 쌓는다. 그로기 게이지가 다 차면 보스가 그로기 상태에 들어간다. 전조와 무관한 교체도 멀리서 적에게 접근해 공격하지만 게이지를 쌓는 강한 공격은 아니다. 캐릭터는 일반 공격, 일반 스킬, 궁극 스킬을 가진다. 기믹형이 아닌 보스 공격에는 모두 전조가 있다 | 붉은색 공격은 반격이 되지 않고 회피만 가능. 궁극 스킬은 적을 공격해 게이지를 채워 쓴다 (충전 효율 옵션이 있어 게이지 구조는 간접 확인, 채우는 조건은 미확인). 행동 중 교체하면 하던 행동을 끝까지 수행한 뒤 퇴장. 난투 직업군은 교체 뒤 4초 더 공격한 뒤 퇴장 (재현하지 않음) |
| 조작과 타이밍 | 회피와 교체의 입력 창은 같은 길이로 보인다 | 입력 창의 길이 (수치 없음) |
| 수치 | 태그 쿨타임은 10초 이상 (확인). 플레이에서는 캐릭터당 16~20초로 보였다. 재현 설계값은 15초 | 스킬 사용으로 태그 쿨타임이 줄어드는 듯하다 (출처가 엇갈리고 캐릭터 고유 조건일 수 있음). 보스 패턴은 7~8가지 |
| 반응 (화면, 소리, 멈춤) | 그로기 발동은 전용 연출 (고양이가 보스에게 던져지고, 캐릭터의 눈 클로즈업 뒤 보스를 구속하는 애니메이션) | 전조의 소리와 멈춤 |

## 내가 만들어서 확인할 것

게임의 핵심 시스템을 재현해보는 것으로 게임 개발 실력을 높이고, 해당 IP를 이용하여 빌드할 창작 게임에 관한 실마리를 얻는다. 또한 이번에 만들 해당 캐릭터의 에셋을 이용하여 창작 게임의 토대를 세울 수 있다.

- 확인할 가설: 전투의 핵심 재미를 만들기 위해서는 속도감을 더해주는 방법이 있고, 이는 전투 시에 타이밍에 맞춰 특정 행동을 하게 하고 이에 대한 피드백을 연출, 혹은 보상의 형태로 제공하는 것이 유효하게 작용한다.
- 작게 줄인 모습: 위에서 본 2D 화면. 보스 하나(패턴 3개, 노란 전조 2개와 붉은 전조 1개). 캐릭터 셋(일반 공격, 특수 스킬, 궁극 스킬을 하나씩 가짐). 조작은 이동, 공격, 회피, 교체, 특수 스킬, 궁극 스킬 여섯. 그로기 게이지가 다 차면 보스가 멈추고 큰 데미지. 한 판 1분에서 2분. 일반 스킬, 지원 스킬, 몬스터는 뺀다. 첫 판(프로토타입)에서는 캐릭터를 색만 다른 도형으로 그리고, 그림은 나중에 정한다
- 한 문장: 보스 공격의 전조가 빛나는 순간 회피나 교체를 누르면 반격이 터지는, 세 캐릭터 태그 보스전 한 판
